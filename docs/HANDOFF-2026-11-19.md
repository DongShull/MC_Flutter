## 四、飞牛逆向：工具链与关键发现（已全部装好、可直接复用）

### 工具链（都已安装并实战验证）
- **REA**：rea-agents 6.9.0（morluto/rea，npm 全局装；clone 在 /opt/rea）
- **jadx** 1.5.1：/opt/re-tools/bin
- **apktool** 2.11.1
- **blutter**（自编译成功，最难的一环）：
  - 坑 1：gcc11 编不了 Dart 3.11.5 的 C++20 代码 → 换 clang
  - 坑 2：clang14 缺 `<format>` → 从 apt.llvm.org 装 clang-17 + libc++-17-dev
  - 坑 3：DartVM 必须与 blutter 用同一 stdlib —— 纯 libc++ 全链重编后才跑通
  - 坑 4：链接错误时把 `/lib/x86_64-linux-gnu/libstdc++.so.6` 放进
    `CMAKE_CXX_STANDARD_LIBRARIES` 最后才成功（纯 libc++ 后不再需要）
  - capstone 5/6：从源码 /opt/re-tools/capstone build 装到 /usr/local
  - 用 gdb 定位过 crash：DartApp::loadFromClassTable —— 根因就是双 stdlib 混链

### 关键逆向发现
1. **播放会话协议**（最有价值，已回填）：`trim_playback_session_plugin` Pigeon 接口面全还原——
   `HostPlaybackSessionApi{initialize, registerParticipant, unregisterParticipant,
   reportParticipantState, reportRemoteUserPaused, reportUserStopped, requestActivation,
   synchronize, acknowledgeCommand}` +
   `FlutterPlaybackSessionApi{onCoordinatorCommand, onSessionSnapshotChanged, onSessionDiagnostic}`；
   失败口径：participant_command_timeout / execution_failed / pin_legacy_failed /
   register_failed / reregister_failed / resume_failed；还有 `X-TRIM-IJK-Transcode-HLS` 请求头。
2. **播放内核是 ijkplayer**（libijkplayer/libijkffmpeg），不是 ExoPlayer。
3. **鸿蒙适配方式**：同一份 Dart 代码 + 运行时探测
   （`trim_base_plugin.HarmonyUtilApi.isHarmonyOS / harmonyOSVersion`）+
   各插件的 ohos 分支 + 独立 CI 产物。本 APK 内无 ohos so。
4. **全部 134 个 Pigeon 通道分布**：nas 62 / trim_common 19 / video_player_android 15 /
   playback_session 12 / base 8 / media 6。
5. **Dart 类名被混淆**（可读类名仅 4 个）——函数级还原需读汇编或真机 Frida，静态已榨干。
6. 飞牛 App 本身就是 Flutter 写的（libflutter.so + libapp.so + dartjni，包名 com.teiron.*），
   也用官方 video_player；内部插件：trim_playback_session_plugin / trim_native_download /
   trim_cast_plugin 投屏 / trim_ui 自有设计系统 / trim_http_client / trim_media；
   mmkv 含 mmkv_ohos（佐证鸿蒙路线）；启动优化：EndWarmUpFrame 预热帧 / lazyPut /
   deferred 加载 / preloadArtwork / RequestDartPerformanceMode / HostKeepAliveApi /
   libgojni 12MB Go 传输层。

### 飞牛 APK 下载的教训
- 官方直链（download.liveupdate.fnnas.com / iso.liveupdate.fnnas.com）全部 403，
  nginx `X-Error-Info: typeC` = IP 归属地封锁海外数据中心；换 UA/Referer/HTTP1.1/Range/
  wget/真浏览器都没用；当贝镜像（qingyingyong.net）与 znds 也失败。
- **结论：必须用户在国内网络下载**。最终用户上传了 APK 本体。
